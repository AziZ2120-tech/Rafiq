# رفيق (نموذج أولي)

صفحة ويب ثابتة (HTML وJavaScript بدون خادم). تقدر تثبّتها على شاشة الجوال الرئيسية كتطبيق.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub (عام). 
2. ارفع محتويات هذا المجلد كما هي (index.html وmanifest.webmanifest ومجلد icons وملف .nojekyll).
3. من إعدادات المستودع افتح Pages واختر النشر من الفرع main والمجلد الرئيسي.
4. بعد دقائق يظهر الرابط: https://اسم-المستخدم.github.io/اسم-المستودع/

## ملاحظات
- لا تضع مفاتيح أو كلمات سر في أي ملف هنا. المستودع عام.
- الصفحة تتصل بخدمة Overpass العامة من جهاز المستخدم وترسل موقعه. مناسب للتجربة فقط.
- شروط GitHub Pages تمنع استخدامه استضافة مجانية لمنتج تجاري. عند الإطلاق ننقل الصفحة لاستضافة تسمح بذلك.
- إجابات المستخدم تُحفظ في متصفحه فقط.
